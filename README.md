# Зигзаг Нуля

Кроссплатформенное десктоп-приложение (Electron + React + TypeScript) для построения,
визуального редактирования и мониторинга карты сетевой топологии, а также для
инвентаризации IT-оборудования и программного обеспечения.

> Прототип, реализующий все разделы технического задания.

## Возможности

### Построение и редактирование топологии
- **Автоматическое сканирование сети** — ping-sweep по CIDR, чтение ARP-таблицы,
  определение типа устройства по SNMP (`sysServices` / `sysDescr`), разрешение DNS-имён.
- **Ручное редактирование** — палитра устройств, размещение по клику, перетаскивание,
  изменение свойств в инспекторе.
- **Автоматическое построение связей** — опрос соседей по **LLDP** (LLDP-MIB),
  **Traceroute** и данных **SNMP**.
- **Расширенный SNMP** — `get` / `walk` по произвольным OID и приём **SNMP-trap**
  (асинхронные аварии оборудования).

### Визуальный редактор
- Ручное добавление и редактирование связей между устройствами.
- Произвольные текстовые надписи.
- Зоны (области) с заливкой цветом/прозрачностью и подписью для группировки сегментов.
- Встроенная библиотека векторных значков сетевых устройств.

### Виджеты на элементах схемы
- **Пинг-мониторинг (ICMP)** — IP и интервал опроса; зелёный кружок при доступности,
  мигающий красный при недоступности; **звуковая тревога** (свой MP3/WAV/OGG или
  встроенный сигнал) с возможностью отключения звука.
- **Web-интеграция** — иконка-глобус, открытие ссылки в системном браузере.
- **Заметки** — иконка-карандаш, окно просмотра с кнопкой «Редактировать» и
  «Сохранить и закрыть».

### Инвентаризация и учёт IT-активов
- Учёт оборудования (компьютеры, сетевое оборудование, принтеры и т.д.).
- Учёт ПО и лицензий (сроки действия, количество активаций).
- История изменений конфигураций.
- Планирование апгрейдов ПК на основе собранных характеристик.
- Отчёты и экспорт в CSV.
- Хранилище — SQLite (через `sql.js`), привязка активов к устройствам на схеме.

### Файлы и экспорт
- Сохранение проекта в собственном формате **`.zigzag`** (JSON-схема).
- Экспорт схемы в **PNG**, **SVG**, **PDF** и печать.

## Технологии
- Electron 31, React 18, TypeScript 5
- electron-vite (сборка), electron-builder (упаковка)
- Konva / react-konva (canvas-редактор), zustand (состояние)
- net-snmp (SNMP/trap), ping (ICMP), sql.js (БД), jsPDF (PDF)

## Разработка

```bash
npm install        # установка зависимостей
npm run dev        # запуск в режиме разработки
npm run typecheck  # проверка типов
npm run lint       # ESLint
npm run build      # типы + production-сборка
```

## Сборка дистрибутивов

```bash
npm run build:win    # Windows (NSIS)
npm run build:mac    # macOS (dmg)
npm run build:linux  # Linux (AppImage)
```

## Структура

```
src/
  main/        # Electron main process
    network/   # ping, ARP, SNMP, traceroute, LLDP, scan, trap
    db/        # инвентаризация (sql.js)
    files/     # .zigzag, экспорт, настройки
  preload/     # безопасный мост (contextBridge → window.zigzag)
  renderer/    # React UI (редактор, инспектор, панели, инвентаризация)
  shared/      # общие типы и имена IPC-каналов
```

## Замечания
- Для пинга используется системный `ping` (без raw-сокетов и прав root).
- Приём SNMP-trap на стандартном порту 162 может требовать прав администратора —
  в прототипе можно указать любой UDP-порт.
